№7 - 8 тиктокеров участвуют в челлендже " 24 часа без телефона ". Известен перечень просмотров ( в тысячах ) каждого тиктокера, записанный в порядке убывания. Ни у одной пары тиктокеров нет одинакового количества просмотров. Определить, какое место занял тиктокер, набравший N тысяч просмотров. Место определяется по количеству просмотров: больше просмотров — выше место. Условный оператор не использовать.
